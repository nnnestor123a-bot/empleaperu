# Entregables del Proyecto — EmpleaPerú

1. **Aplicación Full-Stack Next.js + TypeScript + Tailwind + Prisma/SQLite:**
   - Sitio público comercial completo (`/`, `/empleos`, `/empleos/[slug]`, `/empresas`, `/empresas/[id]`, `/practicas`, `/salarios`, `/mapa`, `/ferias`, `/servicios`, `/nosotros`, `/contacto`, `/ayuda`, `/privacidad`, `/terminos`, `/portafolio/[slug]`).
   - Portal Postulante (`/postulante`, `perfil`, `cv`, `postulaciones`, `favoritos`, `entrevistas`, `carrera`, `evaluaciones`, `portafolio`).
   - Portal Empresa & ATS (`/empresa`, `vacantes`, `ats`, `perfil`, `planes`).
   - Mensajería (`/mensajes`), Notificaciones (`/notificaciones`), EmpleaBot flotante y Panel de Administración (`/admin`).
2. **Base de datos SQLite local y Seed idempotente:** `prisma/schema.prisma`, `prisma/seed.ts`, `prisma/dev.db`.
3. **Pruebas y Operaciones:** `tests/core.test.ts`, `scripts/backup.mjs`, `scripts/restore.mjs`, `INICIAR_PROYECTO.bat`, PWA (`public/manifest.json`, `public/sw.js`, `public/icon.svg`, `/offline`).
4. **Documentación integral (`docs/`):** `REQUERIMIENTOS.md`, `ARQUITECTURA.md`, `BASE_DE_DATOS.md`, `DIAGRAMA_ER.md`, `PRODUCT_BACKLOG.md`, `PLAN_SPRINTS.md`, `CRONOGRAMA.md`, `MATRIZ_RIESGOS.md`, `MATRIZ_KPI.md`, `MATRIZ_TRAZABILIDAD.md`, `SEGURIDAD.md`, `PLAN_PRUEBAS.md`, `RESULTADOS_PRUEBAS.md`, `MANUAL_USUARIO.md`, `MANUAL_INSTALACION.md`, `ENTREGABLES.md` y `PROGRESO.md`.

# Skill de desarrollo EmpleaPerú
Lee AGENTS.md y docs/ESPECIFICACIONES.md completos. Consulta docs/PLAN.md y PROGRESO.md. Inspecciona el entorno Windows y el repositorio antes de modificarlo. Implementa la primera fase pendiente, ejecuta pruebas, revisa el navegador y registra resultados verificables. Continúa por fases mientras no existan bloqueos. No declares terminada una función sin evidencia. Mantén el servidor en 127.0.0.1:3000 cuando sea posible. Si la detección automática de skills no funciona, estas instrucciones también se pueden ejecutar leyendo este archivo directamente.

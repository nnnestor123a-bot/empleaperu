# Instrucciones permanentes
- Lee docs/ESPECIFICACIONES.md y docs/PLAN.md antes de programar.
- Implementa código funcional, no solo diseños o explicaciones. Prioriza el sitio público y el flujo completo de contratación.
- Trabaja dentro del repositorio; no borres datos, no publiques código ni expongas puertos a Internet sin autorización. No compres servicios.
- Usa versiones estables compatibles, lockfile, variables de entorno y Git local. No incluyas secretos ni datos personales reales en Git.
- Aplica autorización en servidor, aislamiento entre empresas y protección de CV. No uses atributos protegidos para evaluar candidatos.
- Distingue demostración, reglas heurísticas e IA generativa real. No inventes resultados de pruebas, salarios, verificaciones SUNAT ni pagos.
- Después de cada fase ejecuta lint, typecheck, pruebas y build según corresponda; registra comandos, resultados y bloqueos en PROGRESO.md. Haz commits locales si Git está configurado.
- No reemplaces módulos funcionales sin justificación. Mantén criterios de aceptación y trazabilidad.
